# Relityx — instaladores

Análise offline de oscilografias (COMTRADE, Reyrolle) e backups de relés de proteção.

Este repositório guarda só os instaladores; o código-fonte é privado.

## Baixar

Na [última versão](https://github.com/mattdavii/relityx-releases/releases/latest):

| Sistema | Arquivo |
|---|---|
| Linux (qualquer distribuição) | `Relityx_X.Y.Z_amd64.AppImage` — dar permissão de execução e abrir |
| Debian, Ubuntu, Mint | `Relityx_X.Y.Z_amd64.deb` — `sudo apt install ./Relityx_X.Y.Z_amd64.deb` |
| Windows 10/11 | `Relityx_X.Y.Z_x64-setup.exe` — se o SmartScreen avisar, "Mais informações" → "Executar assim mesmo" |
| Android | `Relityx_X.Y.Z_android.apk` — permitir a instalação de fontes desconhecidas |

O app pede uma chave de ativação na primeira abertura: envie ao responsável o código da máquina mostrado na tela.

O app avisa sozinho quando sai uma versão nova. Nos computadores, "Atualizar agora" instala e reinicia. No Android (a partir da 0.2.1), o app baixa a versão nova e abre a instalação: toque em "Instalar"; na primeira vez, permita que o Relityx instale apps. Quem tem a 0.2.0 no celular instala a 0.2.1 por cima uma vez, baixando o APK desta página.

Os diagnósticos exibidos pelo Relityx são apoio à análise e precisam de validação técnica.
